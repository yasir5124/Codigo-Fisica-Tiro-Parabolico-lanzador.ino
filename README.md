# Codigo-Fisica-Tiro-Parabolico-lanzador.ino
Catapulta robótica de lanzamiento controlado Código para Arduino Uno de una catapulta robótica que lanza un proyectil hacia un objetivo, usando el modelo del movimiento parabólico.  Proyecto del Taller de Investigación: Modelación y validación experimental del movimiento parabólico.
